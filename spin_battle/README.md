# Spin Battle — битва волчков 🌀

Аркадная игра на Python + pygame в духе Beyblade. Ты собираешь волчок —
выбираешь **форму** (шар или куб), **вес** и **материал** — запускаешь его на
арену, и волчки сами носятся, сталкиваются и сбивают друг другу «раскрутку».
Кто докрутится до нуля — проиграл. Матч идёт до 2 побед (лучший из 3).

## Установка и запуск

```bash
cd spin_battle
pip install -r requirements.txt
python main.py
```

Headless-проверка без окна (для CI/серверов):

```bash
python main.py --smoke-test
```

## Управление

Игра работает и на ПК (клавиатура + мышь), и на телефоне (тапы по экрану).

| Действие | ПК (клавиши) | Телефон |
|----------|--------------|---------|
| Меню / выбор в сборке | ← → (или A/D), вверх/вниз | тап по кнопке `<` `>` |
| Подтвердить / дальше | Enter или Пробел | тап по кнопке «Дальше / В БОЙ» |
| Назад в сборке | Backspace | — |
| **Буст (спецудар) — Игрок 1** | Пробел | кнопка «БУСТ P1» |
| **Буст (спецудар) — Игрок 2** | Enter | кнопка «БУСТ P2» |
| Дальше после раунда | Enter | тап по экрану |
| В меню / выход | Esc | — |

Буст — это рывок к сопернику; если попасть им в врага, удар наносит усиленный
урон и срабатывает супер-анимация (искры + тряска экрана). У буста есть кулдаун:
жёлтое кольцо вокруг волчка означает, что спецудар готов.

## Как это работает (баланс)

**Форма**
- **Куб** — агрессивный: бьёт сильнее, но быстрее теряет раскрутку (выше трение).
- **Шар** — стабильный: урон меньше, зато крутится дольше.

**Вес**
- **Тяжёлый** — мощный нокбэк и большой запас раскрутки, но инертный (хуже манёвр).
- **Лёгкий** — быстрый и вёрткий, но запас раскрутки меньше.

**Материал**
- **Металл** — прочный и тяжёлый.
- **Дерево** — сбалансированное.
- **Резина** — прыгучая (сильные отскоки), чуть легче.

**Арена**
- Круглое поле с бортиком (отскок + потеря раскрутки).
- Случайные бамперы-препятствия, которые сбивают траекторию и добавляют хаоса.

## Режимы

- **Против ИИ** — твой волчок против случайно собранного компьютерного.
- **Два игрока** — оба собирают волчки и бустят своими клавишами за одним ПК.

## Структура проекта

```
spin_battle/
├── main.py            # цикл игры и автомат состояний (меню → сборка → бой)
├── game/
│   ├── config.py      # все числа баланса и физики
│   ├── top.py         # волчок: характеристики, движение, отрисовка, буст
│   ├── physics.py     # столкновения (волчки, стены, бамперы), урон
│   ├── arena.py       # арена и препятствия
│   ├── effects.py     # частицы и тряска экрана (супер-анимация)
│   └── ui.py          # меню, сборка волчка, HUD, экраны раундов
└── tests/
    └── test_physics.py  # юнит-тесты физики (без окна)
```

## Android (APK) 📱

Игра упаковывается в Android-приложение через `buildozer`. APK собирается
**автоматически на серверах GitHub** — локально Android SDK не нужен.

### Как скачать готовый APK

1. Открой репозиторий на GitHub → вкладка **Actions**.
2. Выбери последний запуск workflow **«Build Spin Battle APK»** (он стартует сам
   при изменениях в `spin_battle/`; можно запустить вручную кнопкой
   **Run workflow**).
3. Дождись зелёной галочки (первая сборка идёт ~15–25 минут).
4. Внизу страницы запуска, в разделе **Artifacts**, скачай **`spin-battle-apk`** —
   внутри `.apk`.
5. Перекинь файл на телефон и установи (включи «Установка из неизвестных
   источников» для своего файлового менеджера/браузера).

### Собрать APK самому (Linux)

```bash
pip install buildozer cython
cd spin_battle
buildozer android debug      # готовый apk появится в spin_battle/bin/
```

Конфигурация сборки — в `buildozer.spec`, сам процесс CI — в
`.github/workflows/build-apk.yml`.
